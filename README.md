# 📅 Personal Meeting & Booking System

A full-stack, production-ready booking and scheduling application built with Next.js, TypeScript, and Firebase.

## 🛠️ Tech Stack

*   **Frontend & Backend:** Next.js (App Router), React, TypeScript
*   **Database & Backend Services:** Firebase
*   **Email Notifications:** Resend API
*   **Styling:** CSS
*   **Deployment:** Vercel

## ✨ Features

*   **Dynamic Booking System:** Seamless public-facing booking interface paired with a secure administrative dashboard.
*   **API Routes & Middleware:** Implements custom Next.js backend routes and middleware for secure request handling and authentication flows.
*   **Automated Email Alerts:** Integrated with Resend to dispatch instant, professional email notifications for meeting schedules and updates.
*   **Responsive UI:** Fully optimized for smooth scheduling experiences across all devices.
